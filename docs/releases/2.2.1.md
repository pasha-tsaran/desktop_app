## Scope

- Removed the `12 цифр` input placeholder, including on focus. The input
  remains empty; numeric filtering and 12-digit validation are unchanged.
- Implemented a native Windows notification icon with open/exit menu,
  hide-on-close/minimize when enabled, restore-on-click and restore-before-
  disable. Explorer restart recreates the icon. If icon registration fails,
  the window is not hidden and VPN automation can still start.
- Explicit tray exit warns that the GUI closes while the VPN service/current
  tunnel continue running. Automatic network/sleep recovery requires the GUI.
- The setting is saved only after the native change succeeds. Debug mocks do
  not interact with the real system tray. Native code sends no VPN commands.
- Privacy policy is a fixed bundled two-page Russian PDF, rendered locally
  through pinned pdfrx 2.6.1/PDFium, with back navigation, zoom and page count.
  No browser, online PDF viewer or remote policy fetch is used.
- The owner supplied by the user is Царан Павел Андреевич. This is a basic
  policy, not a verified legal/compliance statement. Contact information,
  server retention and logging practices remain explicitly unconfirmed.
  It does not promise a no-logs service or absolute anonymity.

## Delivery and regression boundary

`tool/build-ui-update.ps1` builds 2.2.1 against the pinned 2.2.0 installer.
All eight service/engine/driver files are copied without recompilation and
hash-checked again after final installer extraction. Only the desktop app and
its viewer dependencies/assets change. PDFium redistribution notices are
included under licenses/pdfium. Earlier installers are not overwritten.

The existing installed 2.2.0 was not updated by the development/build steps.
Service/driver rules, server configuration, credentials, routes and live VPN
connections were not modified.
