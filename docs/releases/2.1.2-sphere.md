# Kenai VPN 2.1.2 — сфера и панель задач

Версия интерфейса и установщика: 2.1.2, номер сборки: 14.

## Изменения

- Сворачивание оставляет окно на панели задач Windows. Закрытие крестиком
  при включённом трее скрывает окно, восстановление возвращает его на экран.
- Логотип с буквой K заменён сферой. Тот же рисунок упакован в Windows ICO
  с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей.
- Шесть пунктов бокового меню используют стеклянные цветные значки по
  пользовательскому референсу. Ассеты общие для обеих тем.
- VPN-служба и движки упаковываются из проверенного исходного установщика
  2.2.2 без изменения байтов. Меняется только клиентское приложение.

## Проверки

Нативный Windows-тест проверяет сворачивание при включённом и выключенном
трее, восстановление и закрытие на отдельном окне: `tray_native_test:OK (0)`.
Снимки светлой и тёмной темы просмотрены в `output/ui-review/`.
Тесты меню используют ключи кнопок вместо старых Material Icons.
Flutter analyze и форматирование: без замечаний. Все 116 тестов клиента
и kenai_core прошли. Windows Release собран; ProductVersion исполняемого
файла проверен: `2.1.2+14`.
Результаты упаковки и SHA256 сохраняются рядом с архивом сборки в `build/`.
Реальное VPN-соединение пользователя при проверках не переключается.

## Изображения

Использован встроенный imagegen, режим редактирования пользовательских
референсов. Рабочие PNG сохранены в `apps/desktop/assets/branding/`:
`sphere-logo.png`, `servers.png`, `account.png`, `logs.png`,
`vpnSettings.png`, `settings.png`, `support.png`.

Задание для логотипа: извлечь стеклянную бирюзово-фиолетовую сферу,
сохранить форму и блики, убрать внешний фон, сделать прозрачный PNG
без букв и квадратной подложки; насыщенная непрозрачная внутренняя часть.

Задание для значков: сохранить шесть стеклянных неоновых символов из
референса, прозрачный фон и пустые области, равномерная сетка 3×2
1536×1024; порядок: глобус, аккаунт, документ, шестерёнка, ползунки,
гарнитура. Цвета: голубой, синий, фиолетовый, розовый, оранжевые блики.
Без текста и плашек. `tool/package-branding.ps1` извлекает ячейки атласа
и упаковывает логотип в ICO, сохраняя исходный альфа-канал.

## Выдача

Установщик распакован: проверен 61 файл, 8 файлов VPN-службы и движков
совпадают с исходной версией по SHA256. Контрольная сумма установщика:
`08F3E955D5ED2F787F86C3FB9B05B373B4287C2C9C1742A3842467C2187F1ED4`.

В пользовательской папке `установщик` оставлен только
`KenaiVPN-Setup-2.1.2-UNSIGNED.exe`.
Старые файлы и каталоги в этой папке удалены по прямому запросу пользователя;
повторная проверка подтвердила ровно один файл и совпадение SHA256.
Исходники, инструменты сборки и копия исходного установщика в `dist/`
сохраняются в репозитории.
