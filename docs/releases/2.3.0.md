# Kenai VPN 2.3.0 — Netherlands direct exit

The production server catalog now offers Armenia and the Netherlands as
separate locations. Netherlands supports VLESS/REALITY only. Selecting it
requests a second per-device profile from the Armenian account API and imports
it through the existing privileged Windows service. The opaque profile handle
is stored separately; a missing NL profile cannot silently connect using the
Armenian profile. Existing activation keys and Armenian profiles remain valid.

The NL server and API rollout is documented in
`control-plane/docs/netherlands-direct-exit.md`. The first NL connection may
need a retry if the newly issued UUID has not yet reached the NL sync timer
(normally within 30 seconds). Revocation can lag by the same amount; the NL
service stops if it cannot refresh the allowlist for 180 seconds.

Run the client and core tests before packaging. Use the configured HTTPS API
origin `https://88.218.94.3:9443`. The installer is unsigned until a trusted
signing certificate is available. Do not replace a currently connected user's
installation without an update window and end-to-end smoke test.
