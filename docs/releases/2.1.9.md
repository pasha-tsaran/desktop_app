# Kenai 2.1.9 (build 9)

## Change

VLESS now selects IPv4-only mode automatically when Windows disables native IPv6
via DisabledComponents. The user's registry, bindings and persistent firewall
settings are not changed. No manual PowerShell commands or IPv6 reboot needed.
The usual dual-stack configuration remains on systems where IPv6 is enabled.

The service installs a temporary non-loopback IPv6 packet block before IPv4-only
Xray starts; inability to install/read back the block or select the correct IPv4
route fails connection. The filter is removed after Xray stops. This is not a
general IPv4 kill switch. The original misleading 'disable another VPN' message
is replaced with a neutral routing-error message.

Xray 26.9.9 is built from pinned upstream source with a small Windows TUN patch:
skip configuration of a family that has no addresses, routes or DNS configured.
The exact modified MPL source ships in licenses/xray/source. AmneziaWG 2.0,
activation API, existing account keys and individual device profiles are unchanged.

## Remaining acceptance

Install the 2.1.9 Windows x64 installer over 1.1.8 on the affected laptop without
changing DisabledComponents=0xffffffff. Confirm VLESS connects, HTTPS and DNS work,
IPv6 cannot bypass it, disconnect restores networking, then AmneziaWG still works
with the same activation. Also confirm dual-stack VLESS on a Windows PC with IPv6
enabled. These live tests are not implied by the automated results above.

The installer is unsigned; the previous 1.1.8 installer is retained for rollback.
This release is not a claim of compatibility with every OS, device or network.
