# Поддержка через Telegram

В меню после «Параметры» добавлена «Поддержка». Пользователь создаёт
обращение с темой и описанием и продолжает переписку внутри приложения.
Статусы: ожидает специалиста, в работе, закрыто. Закрытая переписка остаётся
в истории; можно создать новое обращение. Одновременно допускается одно
активное обращение на аккаунт.

В release используется серверный API `/api/v1/support/`; токена Telegram
в клиенте нет. Сессия поддержки получается по ключу из защищённого хранилища
и не вызывает повторную активацию или изменение VPN-профиля. В режиме
разработки используется локальный MockSupportRepository.

Интерфейс опрашивает сервер каждые пять секунд, пока открыт раздел.
Неподтверждённая отправка сохраняет текст в открытом поле. Повтор использует
тот же request_id. После ухода со страницы неотправленный черновик не хранится.
История отправленных сообщений хранится на сервере. Поддерживаются текстовые
сообщения до 2000 символов; вложения и push-уведомления не реализованы.

На сервере нужны миграция `f7b2c8d93e10`, новый API и отдельный worker.
Переменные окружения: KENAI_SUPPORT_ENABLED,
KENAI_SUPPORT_TELEGRAM_BOT_TOKEN, KENAI_SUPPORT_TELEGRAM_CHAT_ID,
KENAI_SUPPORT_TELEGRAM_ADMIN_IDS. Полная инструкция находится в соседнем
серверном проекте `kenai-vpn.example/docs/support.md` и копируется в поставку.

Без обновления и настройки сервера приём обращений недоступен.
VPN-процессы, драйверы, маршруты и Kill Switch этой функцией не изменяются.
